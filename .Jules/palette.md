## 2026-04-05 - [Added Tooltip to Settings Icon]
**Learning:** In Flutter, adding a `tooltip` to an `IconButton` is a simple, one-line change that provides both visual hints for mouse users and semantic labels for screen readers. This pattern is easily scalable and an impactful accessibility improvement for any icon-only interactive elements.
**Action:** Always verify icon-only buttons have semantic labels, such as tooltips, to ensure accessibility.
