## 2023-10-27 - BLE Scanning Asynchronous Feedback
**Learning:** For asynchronous processes like BLE scanning, providing immediate visual feedback (like a small loading spinner next to the status text) and a clear empty state ("Searching for devices..." or "No devices found") significantly reduces user uncertainty about whether the app is working.
**Action:** When implementing any asynchronous search or scan feature, ensure both an active loading indicator and an informative empty state are present.
