## $(date +%Y-%m-%d) - Adding Tooltips to Icon-Only Buttons in Flutter
**Learning:** In Flutter, adding a `tooltip` property to an `IconButton` (especially when it only contains an `Icon` without text) is a highly effective, low-effort way to improve both visual UX (hover/long-press text) and accessibility (acting as a semantic label for screen readers).
**Action:** When auditing or enhancing UI elements in Flutter applications, proactively check `IconButton` widgets and ensure they have descriptive `tooltip` properties if they lack explicit text labels.
